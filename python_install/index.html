    Python Setup Guide (TD Environment)

    This guide explains how to set up Python in the TD environment, install required packages, and run Jupyter notebooks.

    Step 1 – Request the TD Python Installer

    Request the TD Python Installer for the Python Scripting Language from ServiceNow.
    There is no cost.

    📎 Request Link

    Python Scripting Language

    Python_PythonInstaller_1.0_ADM_R01

    The TD Python Installer allows for selection of various supported versions of Python via a single package request.
    Installing the Python Installer package will add an Installer-Updater utility in your Windows Start Menu, which can be run to:

    • Select your version
    • Update your existing version

    Using this package also configures setup to direct PyPI install requests through TD's Nexus Repository.
    This allows for installation of Python packages and libraries in a safe manner.

    Step 2 – Install Python

    Once the Python Installer is in your Software Center, install the installer.
    Then, using the installer, install Python.
    For example, I installed Python 3.10, 64-bit.

    Note

    This is the base Python scripting language. Libraries are not packaged with the installer.
    This is a major difference from an Anaconda installation.

    Step 3 – Access the TD Nexus Repository

    To install libraries, you need access to the TD Nexus Repository (repo.td.com).
    The repository provides a secure way (inside the TD firewall) to install Python libraries.

    To obtain access, submit a ServiceNow request to join the TD_Engineer AD Group.
    There is no cost.

    📎 Request Link

    AD Domain & Group Selection

    • The AD Domain of the Group can be either BKNG.net or TDBFG.com.

    !!! Note For Economics choose TDBFG.com

    • The AD Group TD_Engineer provides access to https://repo.td.com.

    • You can browse the available packages at:
      https://repo.td.com/repository/pypi-all/simple/

    Important

    Ensure you have Python installed from the Installer and confirm you can access
    https://repo.td.com before proceeding to the next steps.

    Step 4 – Export Your Current Python Libraries

    Obtain a list of all Python libraries you currently have with Anaconda.
    This list will assist you when installing libraries in Python without Anaconda.

    There is a text file with python libraries called requirements.txt, if you know the location of the requirements.txt you can use:

    py -m pip install -rC:\Users\...\requirements.txt

    This created a file named requirements.txt with a list of all installed libraries.

    Note

    You can get the txt file from a colleague.

    Step 5 – Create a Virtual Environment

    1. Open a Windows Command Prompt:

    2. Enter cmd in the Windows Search bar.

    3. Verify that Python with PIP is installed by running: 

      py -m pip --version
      This will return the Python version and installation path.

    4. Create a virtual environment: 

      py -m venv path\\to\\location\\environment_name

    Example:

    py -m venv C:\Users\tap9020\Python310\py_me
    Here, the virtual environment is named py_me.

    Step 6 – Activate the Virtual Environment

    To activate the environment, run: 

    .\\environment_name\\Scripts\\activate

    Example: 

    .\\py_me\\Scripts\\activate

    When activated, the command prompt will display the environment name (py_me).

    Tip

    If you get an error, try: 

    C:\Users\...\Scripts\activate.bat

    Step 7 – Install Python Libraries

    The TD Repository (repo), within the TD firewall, provides access to packaged libraries.
    For example, installing pandas also installs numpy and other dependencies.

    Before installing libraries, ensure pip is updated:

    py -m pip install --upgrade pip

    Install libraries

    Review your requirements.txt file and install required libraries.
    Example: 

    py -m pip install pandas

    If a specific version is required: 

    py -m pip install pandas==1.1.3

    Note

    The repo may provide newer versions of some libraries.
    Be aware that syntax changes may occur if versions differ from your Anaconda environment.

    Step 8 – Install and Run Python with Jupyter Notebook

    1. Open a Windows Command Prompt

    2. run 

      pip install jupyter

    3. Activate your virtual environment: 

      .\environment_name\Scripts\activate

    4. Navigate to your working directory: 
      cd \path\to\your\notebooks
    5. Launch Jupyter Notebook by typing into the following: 
      jupyter notebook

    Jupyter will open, and notebooks originally created in Anaconda should run with minimal changes.
    In some cases, updated library versions may require small syntax adjustments.

    Important

    Make sure Jupyter is installed on your system (pip install jupyter)
