Ensure you have python installed from the Installer and have access to https://repo.td.com before proceeding to the next steps.

    Create a virtual environment.

    Enter 'cmd' in the Search bar to open a Windows Command Prompt on your laptop.

    In the Command Prompt, verify that Python, with PIP, is installed by entering:

    py -m pip --version

    The location of the install and Python version will be returned. Enter the command to create a virtual environment:

    py -m venv path where you want to create the environment and the environment name

    In the example below, I create my virtual environment in C:\Users\williadx\Python310 and I named my virtual environment 'vana' (for virtual Anaconda).

    Activate the virtual environment

    To activate the virtual environment, in the Command Prompt enter: .\environment name\Scripts\activate

    In the example below, my virtual environment is named 'vana'. I will need to activate the virtual environment every time I use Python.

    Notice, the prompt changes to display the virtual environment name after it is activated.

    Note

    Be sure to install jupyter: pip install jupyter

    Install Python libraries

    The TD Repository (repo) is within the TD firewall and provides packaging of libraries to a degree. For example, when I installed pandas, numpy and other libraries, required by pandas, were also installed. I reviewed my requirements.txt file and installed libraries that looked familiar. Generally, I did not include the library version and the repo installed the highest available version. I did not install all the libraries on my list, and I probably missed some that I need.

    Prior to installing libraries, ensure pip is the latest version, in the Command Prompt enter: py -m pip install --upgrade pip

    To install a library, in the Command Prompt enter:

    py -m pip install library name

    Run Python using Jupyter Notebook

    Open a Windows Command Prompt

    Activate your virtual environment, .\environment name\Scripts\activate Switch to the location where you store your notebooks or scripts Enter jupyter notebook
