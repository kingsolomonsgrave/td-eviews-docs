    How to Use py2eviews with Python

    Since py2eviews has dependencies on numpy and pandas they should be imported together

    import numpy as np
import pandas as pa
import py2eviews as ev

    Create a new Eviews file from Python:

    eviewsapp = ev.GetEViewsApp(instance='new', showwindow=True)

    Note

    We called this 'eviewsapp' and this is used in the rest of this page but in practice we could use something shorter such as "ea"

    Make a variable in python into a variable in Eviews

    First create some python pandas series with dates 

    dtsa = pd.data_range('1981q1', periods = 12, freq = 'QE') # give a date range for the index
variable1 = pd.Series([10, 20, 40], index=dtsa, name = "variable1")
variable2 = pd.Series([10, 20, 40], index=dtsa, name = "variable2")```

Use the `PutPythonAsWF` method:

```bash
ev.PutPythonAsWF(variable1, app=eviewsapp) # This will push the variable to Eviews and will automatically align the dates
ev.PutPythonAsWF(variable2, app=eviewsapp, newwf=False) # Pushes variable to Eviews but does NOT create a new work file

    Run Eviews commands:

    ev.Run("eviews code", app=eviewsapp)
ev.Run('pageselect Untitled', app=eviewsapp)
ev.Run('pagerename Untitled annual', app=eviewsapp)

    Pull Eviews data into Python

    var_name = ev.GetWFAsPython(app=eviewsapp, pagename = 'annual', namefilter= 'var_name')

    Syntax:

    py2eviews.GetWFAsPython(app=None, wfname='', pagename ='', namefilter='*')

    This will pull data from EViews into Python with specified options.

    Parameters:

    app: EViews COM application, optional

    A user-defined COM application object.

    wfname: string, optional

    Name of the EViews workfile to pull data from. Must be the full path name. If
no workfile is specified the currently open workfile will be used.

    pagename: string, optional

    Name of the EViews workfile page to be created.

    namefilter: string, optional

    Base name for series to be pulled.

    Returns: out: pandas DataFrame

    A pandas DataFrame containing the series objects pulled from EViews. EViews
series attributes are automatically copied into the attributes of the DataFrame.

    Exiting:

    eviewsapp.Hide()
eveiwsapp = None
ev.Cleanup() #clears the memory allocated to the COM process, not done automatically in interactive mode

    Note

    If you happen to set eviewsapp = None while the EViews application window is still visible, EViews will continue to run. EViews will only shutdown automatically if it is not visible. If you do happen to leave EViews open at the end of your program, you’ll have to manually quit EViews.

    Get single data values from an Eviews workfile

    ev.Get(objname, app=None)

    This code retrives a single piece of eviews data, e.g. a scalar value of string value such as '@pagename", app is optional.

    Push a python object (eg list, dict, numpy array) to Eviews

    ev._BuildFromPython(objectlentht (int), newwf=True)

    The objectlength is an inteter which gives the length of the python object.

    ev._BuildFromPandas(object, newwf=True)

    Takes a pandas object (series, DataFrame, panel or Datetimeindex) to be pushed to EViews.
