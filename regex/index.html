    Regular Expressions in Python

    Introduction

    Python provides the built-in re module for working with regular expressions.

    import re

    With this module you can: - Search text for patterns - Extract matches - Replace or remove matched substrings

    Substitution Example

    Suppose you have the following code:

    text = "C_coef * (dlog(hpius) - dlog(hpius_qef))"

    You want to simplify it to:

    C_coef * (dlog(hpius))

    You can use:

    import re

text = "C_coef * (dlog(hpius) - dlog(hpius_qef))"
new_text = re.sub(r"\s*-\s*dlog\(hpius_qef\)", "", text, flags=re.IGNORECASE)

    The syntax for re.sub is:

    re.sub(pattern, replacement_text, original_text, flags)

    !!! note - \s* matches zero or more spaces - ( and ) escape literal parentheses - flags=re.IGNORECASE makes the match case-insensitive

    General Substitution Example

    For a more general case:

    import re

text = "C_coef * (dlog(hpius) - dlog(hpius_qef))"
new_text = re.sub(r"\s*-\s*dlog\([^(]+_qef\)", "", text)

    This removes any substring of the form:

    -dlog(x_qef)

    regardless of the variable name inside.

    Python Regex Cheat Sheet

    This section lists common regex patterns in Python, with both re.sub (replacement) and re.findall (extraction) examples. Always use raw strings r"..." to avoid escaping issues.

    Note

    • [ ] → one character from this set

    • ( ) → a captured group, referenced as \1, \2, etc.

    • (?: ) → a non-capturing group (cannot be referenced)

    1. Digits and Numbers

    • One or more digits: \d+

      re.findall(r"\d+", "Order 123, item 45")   # ['123', '45']
re.sub(r"\d+", "#", "ID 123, item 45")     # 'ID #, item #'

    • Integer or decimal (with optional minus): -?\d+(?:\.\d+)? 

      re.findall(r"-?\d+(?:\.\d+)?", "3.14 -42 100")   # ['3.14', '-42', '100']

    2. Words and Text

    • Word characters: \w+

      `bash re.findall(r"\w+", "Hello, world!") # ['Hello', 'world']

    • Capitalized word: [A-Z][a-z]+

      re.findall(r"[A-Z][a-z]+", "Alice and Bob met Eve") # ['Alice', 'Bob', 'Eve']

    Note

    • [A-Z][a-z]+ means: - one uppercase letter

    • followed by one or more lowercase letters

    • Specific alternatives (OR): cat|dog|bird

    re.findall(r"cat|dog|bird", "a cat and a dog") # ['cat', 'dog']

    3. Whitespace and Separators

    • One or more whitespace: \s+

      re.split(r"\s+", "a   b\t c\n d")   # ['a', 'b', 'c', 'd']

    • Trim leading/trailing spaces: ^\s+|\s+$

      re.sub(r"^\s+|\s+$", "", "  padded  ")   # 'padded'

    4. Anchors (Start/End)

    • Start of string: ^pattern
    • End of string: pattern$
      re.match(r"^Hello", "Hello world") is not None   # True
re.sub(r"world$", "Earth", "Hello world")        # 'Hello Earth'

    Note

    • ^pattern → match only at the very beginning
    • pattern$ → match only at the very end

    5. Wildcards and Any Character

    • Any char except newline: .

      re.findall(r"h.t", "hat hit hot hut")   # ['hat', 'hit', 'hot', 'hut']

    • Greedy anything: .*

    • Non-greedy anything: .*?
      re.findall(r"a.*b", "a---b a-b")      # ['a---b a-b']
re.findall(r"a.*?b", "a---b a-b")     # ['a---b', 'a-b']

    Note

    • .* → greedy, matches as much as possible
    • .*? → non-greedy, matches as little as possible

    6. Groups and Capturing

    • Capture group: ( … )

      re.findall(r"(\d{4})-(\d{2})-(\d{2})", "2025-08-21")
# [('2025', '08', '21')]

    • Backreference: (\w+) \1

      re.findall(r"(\w+) \1", "go go stop now now")   # ['go', 'now']

    7. Repetitions

    • Zero or more: a*
    • One or more: a+
    • Zero or one: a?
      re.findall(r"colou?r", "color colour")   # ['color', 'colour']

    8. Lookarounds

    • Positive lookahead: \d+(?=\sUSD)
    • Positive lookbehind: (?<=USD\s)\d+
      re.findall(r"\d+(?=\sUSD)", "100 USD, 200 EUR")   # ['100']
re.findall(r"(?<=USD\s)\d+", "USD 100 EUR 200")   # ['100']

    Note

    Lookaheads and lookbehinds assert context but do not consume characters.

    9. Escaping Special Characters

    • Literal dot: \.
    • Literal parentheses: \( and \)
      re.findall(r"\.", "a.b c")           # ['.']
re.findall(r"\(test\)", "(test)")    # ['(test)']

    10. Practical Patterns

    • Email: [\w\.-]+@[\w\.-]+\.\w+
    • URL: https?://\S+
    • Date (YYYY-MM-DD): \d{4}-\d{2}-\d{2}
    • Hex color: #[0-9A-Fa-f]{6}
      re.findall(r"https?://\S+", "Visit https://example.com")
# ['https://example.com']

    Tips

    • Use re.sub for replacements and re.findall for extraction
    • Always use raw strings r"..."
    • Precompile patterns with re.compile() if reused often
