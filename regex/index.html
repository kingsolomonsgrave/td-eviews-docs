    Regular Expressions in Python

    Regular Expressions Introduction

    Using the native package re import re in base python one can search text and find patterns which can then be subbed for other patterns or have the patterns returned.

    Substitution example

    Let's say you have C_coef * (dlog(hpius) - dlog(hpius_qef)) in a program file but you want to have C_coef * (dlog(hpius)).

    In the general case you have C * (dlog(x) - dlog(x_qef)) and you want C_coef * (dlog(hpius))

    you can use the following code (which will be explained later).

    import re

    text = "C_coef * (dlog(hpius) - dlog(hpius_qef))"

    new_text = re.sub("\s*-\s*dlog\(hpius_qef\)", "", text, flags = re.IGNORECASE)

    The syntax for re.sub is re.sub(pattern, repleacement_text, original_text, flags)

    What this does is look for any instances of any number of spaces (zero or more) using \s* followed by a minus sign followed by any number of spaces. The rest of the code looks for hpius_qef. The brackets must be "escaped" by using \( or \) since brackets have a specific meaning in RegEx (Regular Expressions).

    General substitution example

    import re

    text = "C_coef * (dlog(hpius) - dlog(hpius_qef))"

    new_text = re.sub("\s*-\s*dlog\([^(]?*_qef\)", "", text)

    This code uses [^(]?* to look for any text strings that are not opening brackets so instead of looking for hpius this will replace any code of the form:

    -dlog(x_qef) with nothing (i.e. it will erase the text).

    ## Python Regex Cheat Sheet (with re.sub and findall Examples)

    This file lists the most used and useful regular expressions (regex) in Python, with both re.sub (replacement) and re.findall (extraction) examples.
    Always use raw strings r"...“ in Python to avoid escaping issues. Assume import re.

    Note

    [ ] means "one character from this set"

    ( ) means "a captured group , i.e. one that can be referenced later using \1 for the first group \2 for the second etc

    (?:) means "a group that cannot be referenced, ie not captured)"

    1) Digits and Numbers

    • One or more digits: \d+
      Example: re.findall(r"\d+", "Order 123, item 45") -> ['123', '45']
      Example: re.sub(r"\d+", "#", "ID 123, item 45") -> 'ID #, item #'

    • Integer or decimal (optional minus): -?\d+(?:\.\d+)?
      Example: re.findall(r"-?\d+(?:\.\d+)?", "3.14 -42 100") -> ['3.14', '-42', '100']
      Example: re.sub(r"-?\d+(?:\.\d+)?", "NUM", "3.14 -42 100") -> 'NUM NUM NUM'

    2) Words and Text

    • Word characters (letters/digits/_): \w+
      Example: re.findall(r"\w+", "Hello, world!") -> ['Hello', 'world']
      Example: re.sub(r"\w+", "X", "Hello, world!") -> 'X, X!'

    • Capitalized word: [A-Z][a-z]+
      Example: re.findall(r"[A-Z][a-z]+", "Alice and Bob met Eve") -> ['Alice', 'Bob', 'Eve']
      Example: re.sub(r"[A-Z][a-z]+", "Name", "Alice and Bob met Eve") -> 'Name and Name met Name'

    Note

    [ ] defines a character class, and tells regex to look for ONE member of this class

    [ ]+ also defines a character class and tells regex to look for one or more members of this class

    Thus [A-Z][a-z]+ tells regex to look for ONE capital letter followed by one or more common letters

    • Specific alternatives (OR): cat|dog|bird
      Example: re.findall(r"cat|dog|bird", "a cat and a dog") -> ['cat', 'dog']
      Example: re.sub(r"cat|dog|bird", "animal", "a cat and a dog") -> 'a animal and a animal'

    3) Whitespace and Separators

    • One or more whitespace: \s+
      Example: re.split(r"\s+", "a b\t c\n d") -> ['a', 'b', 'c', 'd']
      Example: re.sub(r"\s+", " ", "a b\t c\n d") -> 'a b c d'

    • Trim leading/trailing spaces: ^\s+|\s+$
      Example: re.sub(r"^\s+|\s+$", "", " padded ") -> 'padded'

    4) Anchors (Start/End)

    • Start of string: ^pattern
      Example: re.match(r"^Hello", "Hello world") is not None -> True
      Example: re.sub(r"^Hello", "Hi", "Hello world") -> 'Hi world'

    • End of string: pattern$
      Example: re.search(r"world$", "Hello world") is not None -> True
      Example: re.sub(r"world$", "Earth", "Hello world") -> 'Hello Earth'

    Note

    ^pattern (Start of String Anchor) Example 1 re.match(r"^Hello", "Hello world") is not None # True

    ^ asserts: “the match must start at the beginning.”

    "Hello world" does start with "Hello", so it matches.

    If the string were "Say Hello world", it wouldn’t match, because "Hello" is not at the very beginning.

    Example 2 re.sub(r"^Hello", "Hi", "Hello world")

    'Hi world'

    Regex looks for "Hello" only at the start.

    Finds it at the beginning, replaces it with "Hi".

    Result: "Hi world".

    1. pattern$ (End of String Anchor) Example 1 re.search(r"world$", "Hello world") is not None # True

    $ asserts: “the match must end at the end of the string.”

    "Hello world" does end with "world", so it matches.

    If the string was "Hello world!", it would fail, because "world" isn’t the last thing.

    Example 2 re.sub(r"world$", "Earth", "Hello world")

    'Hello Earth'

    Regex looks for "world" only if it’s at the very end.

    Replaces it with "Earth".

    Result: "Hello Earth".

    1. Key Takeaways

    ^pattern → “Match pattern only if it’s at the very beginning.”

    pattern$ → “Match pattern only if it’s at the very end.”

    They don’t consume characters — they just pin the match to a position.

    5) Wildcards and Any Character

    • Any char except newline: .
      Example: re.findall(r"h.t", "hat hit hot hut") -> ['hat', 'hit', 'hot', 'hut']
      Example: re.sub(r"h.t", "X", "hat hit hot hut") -> 'X X X X'

    • Greedy anything: .*
      Example: re.findall(r"a.*b", "a---b a-b") -> ['a---b a-b']
      Example: re.sub(r"a.*b", "[...]", "a---b a-b") -> '[...]'

    • Non-greedy anything: .*?
      Example: re.findall(r"a.*?b", "a---b a-b") -> ['a---b', 'a-b']
      Example: re.sub(r"a.*?b", "[short]", "a---b a-b") -> '[short][short]'

    Note

    Greedy .* → “grab the whole pie, then backtrack only if necessary.”

    Non-greedy .*? → “grab the smallest slice, then expand only if necessary.”

    6) Groups and Capturing

    • Capture group: (…)
      Example: re.findall(r"(\d{4})-(\d{2})-(\d{2})", "2025-08-21") -> [('2025','08','21')]
      Example: re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\3/\2/\1", "2025-08-21") -> '21/08/2025'

    • Backreference: (\w+) \1
      Example: re.findall(r"(\w+) \1", "go go stop now now") -> ['go', 'now']
      Example: re.sub(r"(\w+) \1", r"\1", "go go stop now now") -> 'go stop now'

    7) Repetitions

    • Zero or more: a*
      Example: re.findall(r"ba*", "b ba baa") -> ['b', 'ba', 'baa']
      Example: re.sub(r"ba*", "B", "b ba baa") -> 'B B B'

    • One or more: a+
      Example: re.findall(r"ba+", "b ba baa") -> ['ba', 'baa']
      Example: re.sub(r"ba+", "B", "b ba baa") -> 'b B B'

    • Zero or one: a?
      Example: re.findall(r"colou?r", "color colour") -> ['color', 'colour']
      Example: re.sub(r"colou?r", "paint", "color colour") -> 'paint paint'

    8) Lookarounds

    • Positive lookahead: \d+(?=\sUSD)
      Example: re.findall(r"\d+(?=\sUSD)", "100 USD, 200 EUR") -> ['100']
      Example: re.sub(r"\d+(?=\sUSD)", "X", "100 USD, 200 EUR") -> 'X USD, 200 EUR'

    • Positive lookbehind: (?<=USD\s)\d+
      Example: re.findall(r"(?<=USD\s)\d+", "USD 100 EUR 200") -> ['100']
      Example: re.sub(r"(?<=USD\s)\d+", "X", "USD 100 EUR 200") -> 'USD X EUR 200'

    Note

    Positive Lookahead (?=...)

    Pattern: \d+(?=\sUSD)

    \d+ → match one or more digits.

    (?=\sUSD) → assert that immediately after those digits, there is a space + "USD".

    ⚠️ Important: the USD part is not consumed, only checked.

    Positive Lookbehind (?<=...)

    Pattern: (?<=USD\s)\d+

    (?<=USD\s) → assert that immediately before the digits, there is "USD " (USD + space).

    \d+ → match one or more digits.

    ⚠️ Again: the "USD " is not consumed, only checked.

    9) Escaping Special Characters

    • Literal dot: \.
      Example: re.findall(r"\.", "a.b c") -> ['.']
      Example: re.sub(r"\.", "-", "a.b c") -> 'a-b c'

    • Literal parentheses: \( and \)
      Example: re.findall(r"\(test\)", "(test) (prod)") -> ['(test)']
      Example: re.sub(r"\(test\)", "X", "(test) (prod)") -> 'X (prod)'

    10) Practical Ready‑Made Patterns

    • Email: [\w\.-]+@[\w\.-]+\.\w+
      Example: re.findall(r"[\w\.-]+@[\w\.-]+\.\w+", "a@b.com x@y.co.uk") -> ['a@b.com', 'x@y.co.uk']
      Example: re.sub(r"[\w\.-]+@[\w\.-]+\.\w+", "[hidden]", "a@b.com x@y.co.uk") -> '[hidden] [hidden]'

    • URL: https?://\S+
      Example: re.findall(r"https?://\S+", "Visit https://example.com and http://a.io") -> ['https://example.com', 'http://a.io']
      Example: re.sub(r"https?://\S+", "[link]", "Visit https://example.com and http://a.io") -> 'Visit [link] and [link]'

    • Date (YYYY-MM-DD): \d{4}-\d{2}-\d{2}
      Example: re.findall(r"\d{4}-\d{2}-\d{2}", "Due 2025-08-21") -> ['2025-08-21']
      Example: re.sub(r"\d{4}-\d{2}-\d{2}", "DATE", "Due 2025-08-21") -> 'Due DATE'

    • Hex color: #[0-9A-Fa-f]{6}
      Example: re.findall(r"#[0-9A-Fa-f]{6}", "bg #FF00AA text #abc123") -> ['#FF00AA', '#abc123']
      Example: re.sub(r"#[0-9A-Fa-f]{6}", "COLOR", "bg #FF00AA text #abc123") -> 'bg COLOR text COLOR'

    Tips

    • Use re.sub for replacements and re.findall for extraction.
    • Use raw strings (r"...") to avoid escaping confusion.
    • Precompile patterns with re.compile() if reused often.
